# Artwork

| File | Use |
|---|---|
| `mangaki-logo.png` | The mascot alone. Source for every launcher icon — run `tools/generate_launcher_icons.py` against this, never against the wordmark. |
| `mangaki-wordmark.png` | Mascot plus name and tagline. For the README, the About screen, and store listings, where there is room to read it. |

A launcher icon is drawn about 4mm wide. Text in it is unreadable and only
takes space from the mark people actually recognise, which is why the two are
kept apart.
